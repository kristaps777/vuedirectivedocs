# Vue Directives Docs for Laravel

Generates IDE documentation for your custom Vue directives, provided you have declared it properly.

### Directive name
If your directive has a custom name, provide this name in docblock with @directive notation.

* @directive my-custom-directive

If you do not, it will be generated by transforming the file name of your directive to kebab case.

### Directive description
Anything you provide within docblock with @description notation.

### Installation

```bash
composer require kristapsv/vuedirectivedocs --dev
```
Publish the config file. This is where you can define the path to your directives directory and any excludes, if necessary.
```bash
php artisan vendor:publish --tag=vue-directives-docs-config
```
Publish the stub file. This file will be used as basis for documentation.
```bash
php artisan vendor:publish --tag=vue-directives-docs-stubs
```

### Usage
Generate docs file with
```bash
php artisan make:vue-directive-docs
```
This will generate web/vue-directives-docs.json file. Include the file in your package.json under "web-types".
